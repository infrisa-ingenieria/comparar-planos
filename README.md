# Comparar planos (INFRISA)

Página que superpone dos revisiones de un plano de Autodesk Docs (rojo / azul) con el visor de Autodesk Platform Services.
Cada usuario inicia sesión con su propia cuenta de Autodesk; la página no guarda ni envía datos a ningún otro sitio.
Sin secretos: solo el Client ID público de la aplicación.
